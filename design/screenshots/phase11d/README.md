# Flashcard visual references

These intentionally tracked screenshots show authored flashcard content from a
disposable local preview, without private learner data or recordings. Mobile views
are desktop-browser emulation at approximately 390 CSS pixels; desktop views use
approximately 1440 CSS pixels. Raster sizes can vary with browser zoom/scrollbars.
They are visual references, not proof of physical-device compatibility.

Current flashcard behavior is documented in [features](../../../docs/features.md).
Generated responsive measurements remain ignored local execution evidence. Image
files and intentionally tracked design assets are preserved.
